Roadmap update · September 22, 2026

Our goal is simple: **build the payment and service layer AI agents can actually use.** We are starting with payments on Robinhood Chain, bringing useful API projects into a marketplace, and expanding access across chains.

## Phase 1: Agent payments

**Live**

We have built the MCP for AI payments on Robinhood Chain. MCP (Model Context Protocol) gives AI agents a way to connect to tools and services. The payments MCP serves as the core payment layer for AI agents and project builders.

This foundation connects agents with paid services so builders can make their APIs available through a shared payment flow.

[Read the agent integration guide](/developers/agents)

## Phase 2: API marketplace

**Next**

The launchpad already provides API publishing, Explore, and machine-readable discovery. This phase focuses on growing that foundation into a marketplace of useful API projects, bringing more paid services to agents and builders.

The focus is on practical APIs across:

- **Market data:** information for market analysis and monitoring.
- **Onchain data:** blockchain activity and network information.
- **Research:** information gathering and analysis workflows.
- **Document processing:** extracting and working with information from documents.

The payment layer from Phase 1 will support this service ecosystem, with room for more useful API categories as it grows.

## Phase 3: Multi-chain expansion

**Upcoming**

Robinhood Chain remains the main focus, with $OLANAS at the center of the ecosystem. We plan to expand to Base and Solana, extending the payment and service layer to more agents and builders.

This phase includes planned integrations across PayAI, Coinbase and Cloudflare. These are roadmap targets; their inclusion here does not announce a live integration or partnership.

## What we are building toward

A connected path from **agent request** to **payment** to **useful API result**. Each phase builds on the previous one: establish the payment foundation, grow the services available through it, then expand its reach.

The phases describe our current direction. Delivery dates for the next phases have not been announced.

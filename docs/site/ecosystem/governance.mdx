---
title: "Governance status"
description: "The boundary between the operating API launchpad and future token governance."
---

The current launchpad implements wallet-signed management of API listings and owner-approved payments. Those controls are product permissions, not token governance.

## What owners control today

Project creators sign listing creation and supported management actions. Agent owners approve website orders or configure local spending sessions.

Holding OLANAS does not by itself grant control over another project's API, payout address, or orders.

## Token governance

No active token voting or proposal-execution system is documented in the current application. If governance is introduced, its scope, eligibility, voting rules, execution contracts, and safeguards need to be published separately.

See [Token utility](/token/utility) for current payment support and [Roadmap](/ecosystem/roadmap) for product direction.

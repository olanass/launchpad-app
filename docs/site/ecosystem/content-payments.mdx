title: "Sell files"
description: "An additional Olanas workflow for paid file and text downloads."
---

Alongside the API launchpad, Olanas provides **Sell files** for creators who want to sell a downloadable file or text through a payment link.

An API listing calls your hosted service with a buyer's input. A file listing delivers content that you uploaded in advance.

## Create a file listing

1. Open **Sell files** on [Olanas](https://olanas.xyz).
2. Choose a file or paste the text buyers should receive. If a file is selected, it takes precedence over the text.
3. Add the listing title, price, currency, and optional description.
4. Review the listing preview, connect your wallet, and sign the creation message.
5. Save and share the generated payment link.

The preview shows listing metadata, not the private text being sold.

## Buyer flow

The buyer opens the link and reviews its price and payment requirement. The wallet submits the required transfer to the creator's address. Olanas verifies the chain, payer, recipient, asset, amount, and confirmations before releasing the stored content.

The protected download route is `GET /api/paywalls/:id/download`. A request without proof receives an HTTP 402 challenge.

## Storage

The server encrypts content before storing it. Optional IPFS pinning uploads ciphertext. Operators must preserve the encrypted assets and vault secret together to keep downloads recoverable.

Encryption at rest does not prevent a buyer from saving or redistributing content after an authorized download.

## Choose the right workflow

Use **Launch API** for a service that processes requests and returns computed or fetched results. Use **Sell files** for a document, dataset, archive, or text that buyers download after payment.

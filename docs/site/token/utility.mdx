## API payments

The application configures OLANAS as a supported ERC-20 payment asset on Robinhood Chain mainnet. A project can price its API in OLANAS; a buyer of that listing pays the quoted OLANAS amount to the project's payout address.

OLANAS has 18 configured decimals and the contract address `0x9400eB66B1320050A68F25A624985a674F033902`. See [Contract and networks](/token/contract-and-networks) for token reference information.

## What buyers need

The API's listing and quote determine which currency is accepted. Olanas also supports ETH and USDG, with other assets depending on deployment configuration. Holding OLANAS is not required for an API priced in another currency.

A wallet paying an ERC-20 token also needs native ETH for transaction fees on Robinhood Chain.

## Scope of current utility

API payment support is implemented in the shared network configuration and payment verification flow. It does not by itself establish staking, rewards, fee discounts, voting rights, or revenue sharing. Those features are not implemented by selecting OLANAS as a payment currency.

The [roadmap](/ecosystem/roadmap) describes the token's place in the planned ecosystem expansion; future capabilities remain separate from current payment support.

## Utility status

| Capability | Status | Verification |
| --- | --- | --- |
| Content-payment currency | Not announced | Contract and application configuration |
| Governance participation | Not announced | Governance contracts and published process |
| Creator incentives | Not announced | Program rules and distribution addresses |
| Fee discounts | Not announced | Production application behavior |
| Staking or rewards | Not announced | Audited contracts and reward source |

## Documentation rule

A utility should move from **Not announced** to **Available** only when users can use it in production and the docs link to a verifiable interface or contract. Planned features should be labeled **Planned**, with no promise of delivery date or financial return.

## Current payment assets

The existing content-paywall implementation supports native ETH by default. Additional ERC-20 assets are available only when administrators explicitly configure verified contract addresses. That behavior does not establish utility for an Olanas token.

<Warning>
  Do not purchase a token solely because an unofficial source claims it will receive future utility, rewards, listings, or price support.
</Warning>

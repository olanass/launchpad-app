## Contract behavior

The verified contract source shows that the entire initial supply was minted once to the Pons V2 bonding curve. The token contract has no additional mint function and is not a proxy. Holders can burn their own tokens, or tokens for which they have an allowance, so total supply can decrease.

The deployer address stored by the contract is reference metadata only and does not grant special token privileges. Source verification does not mean the contract has received an independent security audit.

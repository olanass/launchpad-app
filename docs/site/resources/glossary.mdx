---
title: "Glossary"
description: "The terms used when publishing and consuming paid APIs on Olanas."
---

| Term | Meaning |
| --- | --- |
| API project | A builder-operated service listed on Olanas with an endpoint, description, and price. |
| Agent | Software that discovers tools and prepares requests on behalf of a user. Payment requires an authorized wallet or policy. |
| Slug | The listing identifier used in its public gateway URL. |
| Gateway | The Olanas route that verifies payment before forwarding a request to the project's endpoint. |
| Upstream endpoint | The API server hosted and operated by the project. |
| Discovery | The searchable catalog and metadata agents use to find APIs. |
| OpenAPI | A machine-readable description of API operations, parameters, and request/response schemas. |
| MCP | Model Context Protocol: the interface through which agent clients access Olanas tools. |
| HTTP 402 | Payment Required: the status returned when a paid route needs payment proof. |
| Payment requirement | The network, asset, amount, and recipient required for a paid request. |
| onchain-tx | Olanas's payment scheme that verifies an already-confirmed blockchain transfer. |
| Durable order | A stored purchase containing the request, quote, approval, payment state, and eventual result. |
| Quote | A versioned snapshot of a purchase's payment and service terms. |
| Access token | A private bearer credential used to access an order. Keep it out of public links and logs. |
| Request ID | A client identifier retained across retries of the same intended purchase. |
| Reconciliation | Checking the original submitted payment and completing eligible order processing without signing a new transfer. |
| Idempotency | Handling repeated attempts as the same operation rather than duplicating its effects. |
| Payout address | The project's wallet address that receives the required payment. |
| Gas | The network fee paid in native ETH on Robinhood Chain. |
| Chain ID | The network identifier. The current application uses `4663`. |
| Transaction hash | The identifier of a submitted blockchain transaction. |
| Wallet signature | Cryptographic approval; signing an order and transferring payment are distinct actions. |

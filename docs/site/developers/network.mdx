title: "Network configuration"
description: "Robinhood Chain mainnet configuration used by Olanas."
---

Olanas supports Robinhood Chain mainnet only.

| Setting | Value |
| --- | --- |
| Chain ID | `4663` |
| CAIP-2 | `eip155:4663` |
| Native currency | ETH |
| Public RPC | `https://rpc.mainnet.chain.robinhood.com` |
| Explorer | `https://robinhoodchain.blockscout.com` |

Leave `ROBINHOOD_NETWORK` unset or use `mainnet`. Other values fail at startup and build time. A custom mainnet RPC can be set through `ROBINHOOD_MAINNET_RPC_URL`. Verification checks the RPC chain ID before accepting a payment.

## Mainnet payment asset

The API launchpad defaults to Global Dollar (`USDG`) on Robinhood Chain:

| Setting | Value |
| --- | --- |
| Symbol | `USDG` |
| Decimals | `6` |
| Contract | [`0x5fc5360D0400a0Fd4f2af552ADD042D716F1d168`](https://robinhoodchain.blockscout.com/token/0x5fc5360D0400a0Fd4f2af552ADD042D716F1d168) |

Native ETH remains available. Other ERC-20 assets appear only when their verified network-scoped contract addresses are configured.

## Storage

Local development uses `X402_DATA_DIR` or `uploads`. Production requires durable Turso storage. Automated tests use isolated databases and mocked payment verification without spending funds.

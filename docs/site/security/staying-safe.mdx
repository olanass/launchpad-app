Crypto transactions can be irreversible. Use this checklist before connecting a wallet or approving a payment.

## Non-negotiable rules

<Warning>
  Olanas support will never ask for your seed phrase, private key, wallet backup, or remote access to your computer.
</Warning>

- Open links from official, bookmarked channels.
- Verify the complete domain before connecting.
- Confirm the wallet displays the intended network, recipient, asset, and amount.
- Never install an unknown wallet extension from a message or advertisement.
- Reject unexpected signatures and token approvals.
- Use a separate wallet with limited funds for unfamiliar applications.
- Remember that testnet tokens have no monetary value.

## Common scams

<AccordionGroup>
  <Accordion title="Fake token or contract">
    A scammer copies the project name and symbol. Verify the contract only on the [canonical contract page](/token/contract-and-networks).
  </Accordion>
  <Accordion title="Fake support">
    An account offers help and asks for a seed phrase, screen share, or wallet synchronization. Stop responding and use only published support channels.
  </Accordion>
  <Accordion title="Approval phishing">
    A site asks for unlimited token approval unrelated to your intended purchase. Reject it and close the site.
  </Accordion>
  <Accordion title="Guaranteed returns">
    Claims of guaranteed profit, fixed appreciation, or risk-free yield are a serious warning sign.
  </Accordion>
</AccordionGroup>

## If something looks wrong

Do not sign. Capture the URL and transaction request, disconnect the site from your wallet, review existing token approvals, and report the incident through a verified Olanas channel once one is published.

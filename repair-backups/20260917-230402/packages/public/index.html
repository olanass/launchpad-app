What is HTTP 402?

When the World Wide Web was conceived in 1991, HTTP status code 402 Payment Required was reserved for native digital payments. For over 30 years, web payments relied on credit card intermediaries, subscription paywalls, and high merchant transaction fees.

Robinhood Chain (Arbitrum Orbit L2) makes true HTTP 402 viable by reducing transaction settlement times to < 190ms and gas costs to < $0.01 USD, enabling direct creator monetization and autonomous machine-to-machine micropayments.

Three Core Pillars

  • ✓
    100% Direct to Creator: Funds settle directly from the buyer's wallet to the creator's Robinhood Chain address. Zero middleman cuts or delayed escrow payouts.
  • ✓
    Military-Grade Vault Security: Assets are AES-256-GCM encrypted before disk storage. Public preview only contains cryptographic SHA-256 proof.
  • ✓
    Frictionless Buyer Experience: Buyers can connect standard Web3 wallets (MetaMask, Coinbase) or sign in instantly with just an email via Privy embedded accounts.

Autonomous AI Agent Micropayment API

cURL Terminal Handshake 
# 1. Probe the paywalled file (Returns HTTP 402 with challenge)
curl -i http://localhost:4020/api/paywalls/pay_demo/download

# Response Headers:
# HTTP/1.1 402 Payment Required
# WWW-Authenticate: x402
# PAYMENT-REQUIRED: {"chainId":4663,"price":"2.50","currency":"USDC","creator":"0x5087...f523"}

# 2. Resend request with signed voucher in PAYMENT-SIGNATURE
curl -i http://localhost:4020/api/paywalls/pay_demo/download \
  -H "PAYMENT-SIGNATURE: 0xcreator_signed_voucher_4663" \
  --output downloaded_asset.pdf
Node.js / JavaScript (ethers.js) 
import { ethers } from 'ethers';

const PAYWALL_URL = 'http://localhost:4020/api/paywalls/pay_demo/download';

// Step 1: Request asset and catch 402 challenge
const initialRes = await fetch(PAYWALL_URL);

if (initialRes.status === 402) {
  const challenge = JSON.parse(initialRes.headers.get('PAYMENT-REQUIRED'));
  console.log('402 Challenge Received:', challenge);

  // Step 2: Sign EIP-712 micropayment with Robinhood Chain wallet
  const wallet = new ethers.Wallet(process.env.AGENT_PRIVATE_KEY);
  const signature = await wallet.signMessage(`x402:${challenge.paywallId}:${challenge.price}`);

  // Step 3: Resend request with PAYMENT-SIGNATURE header
  const paidRes = await fetch(PAYWALL_URL, {
    headers: { 'PAYMENT-SIGNATURE': signature }
  });

  const fileBuffer = await paidRes.arrayBuffer();
  console.log('Payment Settled & Unlocked! Bytes received:', fileBuffer.byteLength);
}
Python (requests & eth-account) 
import requests
from eth_account.messages import encode_defunct
from web3 import Web3

w3 = Web3()
paywall_url = "http://localhost:4020/api/paywalls/pay_demo/download"

# 1. Probe for HTTP 402
r = requests.get(paywall_url)
if r.status_code == 402:
    challenge = r.json()
    
    # 2. Sign micropayment voucher with agent's Robinhood Chain key
    msg = encode_defunct(text=f"x402:{challenge['paywallId']}")
    signed = w3.eth.account.sign_message(msg, private_key="0x...")
    
    # 3. Unlock and download content
    headers = {"PAYMENT-SIGNATURE": signed.signature.hex()}
    download = requests.get(paywall_url, headers=headers)
    
    with open("unlocked_asset.pdf", "wb") as f:
        f.write(download.content)
    print("Download verified & saved successfully!")
